# Prodatix Immutable Cloud Storage

**Platform:** Cloud
**Type:** Immutable Cloud Storage
**Cost:** Enterprise pricing

## Overview

Prodatix offers immutable cloud storage designed to protect data from unauthorized changes. Data cannot be modified, encrypted, or deleted before its retention period expires.

## Key Features

- Tamper-proof storage with retention periods
- Protection against ransomware and cyberattacks
- Veeam Backup & Replication integration
- Automated retention policies
- Multi-site redundancy
- Object storage architecture
- Compliance support for regulatory requirements

## Use for Evidence

Prodatix can serve as immutable storage for evidence archives:

- Set retention periods matching your legal requirements
- Data locked against modification during retention
- Quick restoration from immutable snapshots
- Meets cyber liability insurance standards

## Considerations

- Enterprise-focused solution
- Designed primarily for Veeam environments
