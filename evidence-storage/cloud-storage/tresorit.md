# Tresorit

**Platform:** Windows, macOS, Linux, iOS, Android, Web
**Type:** End-to-End Encrypted Cloud Storage
**Cost:** Paid (various tiers)

## Overview

Tresorit is an end-to-end encrypted cloud storage service designed for secure file storage and sharing. Files are encrypted on your device before upload, meaning Tresorit cannot access your data.

## Key Features

- End-to-end encryption (zero-knowledge)
- Cross-platform sync
- Secure file sharing with permission controls
- Access revocation
- eSign capabilities
- Email encryption add-on
- Compliance certifications (GDPR, HIPAA, CCPA, ITAR)

## Use for Evidence

Tresorit can serve as secure working storage in the [Original and Working Evidence](../../best-practices.md) workflow:

- Store working copies of evidence with strong encryption
- Share specific files securely with legal counsel
- Maintain access logs
- Revoke access when needed

## Considerations

- Not WORM storage (files can be modified/deleted)
- Use alongside [immutable storage](../worm-media/) for chain of custody
- Paid service with storage limits by tier
- Swiss-based company (favorable privacy jurisdiction)
