# Object First Ootbi

**Platform:** Hardware Appliance
**Type:** Immutable Backup Storage
**Cost:** Enterprise pricing

## Overview

Object First Ootbi is a purpose-built immutable storage appliance designed for ransomware-proof backup. It provides "Absolute Immutability" where backup data cannot be altered or deleted, even with admin credentials.

## Product Line

### Ootbi (Enterprise)
- 2U rack-mount appliances
- Capacity: 20 TB to 432 TB
- For mid-to-large enterprises

### Ootbi Mini
- Desktop tower format
- Capacity: 8 TB to 24 TB
- For remote offices and small businesses

## Key Features

- Zero Trust architecture
- S3-native object storage
- Zero Access controls (no destructive actions even with admin)
- Backup speeds up to 8 GB/s
- Automatic load balancing
- 15-minute deployment
- Third-party penetration tested (NCC Group)

## Use for Evidence

Ootbi can serve as an on-premises immutable storage destination:

- Store evidence archives with guaranteed immutability
- Protection against tampering even from administrators
- S3-compatible interface for integration with sync tools
- Physical control over storage location

## Considerations

- Designed primarily for Veeam backup environments
- Enterprise-level investment
- Requires physical installation
- May be overkill for individual use cases
