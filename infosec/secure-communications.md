# Secure Communications

## Overview

When sharing evidence or discussing sensitive investigations, use secure communication channels to prevent interception or leakage.

## Encrypted Messaging

### Signal
**Website:** https://signal.org/
**Platforms:** iOS, Android, Windows, macOS, Linux

- End-to-end encrypted by default
- Open source, audited
- Disappearing messages feature
- Minimal metadata collection
- **Recommended for sensitive communications**

### Wire
**Website:** https://wire.com/
**Platforms:** iOS, Android, Web, Desktop

- End-to-end encrypted
- No phone number required
- Business/team features available
- Swiss jurisdiction

### Comparison

| Feature | Signal | Wire | WhatsApp | Telegram |
|---------|--------|------|----------|----------|
| E2E Encryption | Always | Always | Always | Opt-in only |
| Open Source | Yes | Yes | No | Partial |
| Phone Required | Yes | No | Yes | Yes |
| Metadata | Minimal | Minimal | Collected | Collected |

## Encrypted Email

### ProtonMail
**Website:** https://proton.me/mail
**Cost:** Free tier available

- End-to-end encrypted between ProtonMail users
- Password-protected emails to external recipients
- Swiss jurisdiction
- No IP logging

### Tutanota
**Website:** https://tutanota.com/
**Cost:** Free tier available

- End-to-end encrypted
- Encrypted subject lines
- German jurisdiction
- Open source

### PGP/GPG
For encrypting email with any provider:
- **Mailvelope** (browser extension)
- **GPG4Win** (Windows)
- **GPGTools** (macOS)

## Secure File Sharing

### For Large Evidence Files

**Tresorit Send:**
- End-to-end encrypted file transfer
- Password protection, expiration
- Up to 5GB free

**OnionShare:**
- Uses Tor network
- Self-hosted, no accounts needed
- Open source

**Firefox Send alternatives:**
- **Send.vis.ee** (community instance)
- **Bitwarden Send** (with Bitwarden account)

## Best Practices

1. **Verify recipients** - Confirm identity before sending evidence
2. **Use expiring links** - Set expiration on shared files
3. **Password protect** - Share password via different channel
4. **Don't discuss on unsecured channels** - Assume normal email/SMS is monitored
5. **Document sharing** - Log when and to whom evidence was shared
