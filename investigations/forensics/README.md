# Digital Forensics Tools

Open-source tools and resources for digital forensics investigations.

## Comprehensive Guides

### Digital Forensics Guide
- **Repository**: https://github.com/mikeroyal/Digital-Forensics-Guide
- **Description**: Comprehensive guide covering digital forensics concepts, tools, and techniques

### Awesome Forensics
- **Repository**: https://github.com/cugu/awesome-forensics
- **Description**: Curated list of forensic analysis tools and resources

### ForensicsTools
- **Repository**: https://github.com/mesquidar/ForensicsTools
- **Description**: Collection of scripts and tools for digital forensics

## Forensic Artifact Collections

### Forensic Artifacts
- **Repository**: https://github.com/ForensicArtifacts/artifacts
- **Description**: Machine-readable forensic artifact definitions (registry keys, file paths, etc.) for various operating systems

## Analysis Platforms

### Timesketch
- **Repository**: https://github.com/google/timesketch
- **Developer**: Google
- **Description**: Collaborative forensic timeline analysis tool. Enables creating and sharing timelines from various data sources.
- **Features**:
  - Timeline visualization
  - Collaborative analysis
  - Search and filtering
  - Integration with Plaso/log2timeline

### Kuiper
- **Repository**: https://github.com/DFIRKuiper/Kuiper
- **Description**: Digital forensics investigation platform with modular parser support
- **Features**:
  - Web-based interface
  - Multiple artifact parsers
  - Case management
  - Timeline generation

### Autopsy
- **Website**: https://www.autopsy.com/
- **Description**: Open-source digital forensics platform with GUI interface, built on top of The Sleuth Kit
- **Features**:
  - Disk image analysis
  - File system analysis and recovery
  - Keyword search and hash filtering
  - Timeline analysis
  - Registry analysis (Windows)
  - Web artifact extraction
  - Multi-user case collaboration
- **Platforms**: Windows, Linux, macOS

### IPED (Indexer and Digital Evidence Processor)
- **Repository**: https://github.com/sepinf-inc/IPED
- **Developer**: Brazilian Federal Police
- **Description**: Open-source tool for processing and analysing digital evidence, capable of handling large volumes of data
- **Features**:
  - High-performance indexing
  - Multi-threaded processing
  - OCR for images and PDFs
  - Video and audio analysis
  - Supports hundreds of file formats
  - Regex and keyword searching
  - Gallery view for media
- **Use Case**: Large-scale investigations with terabytes of data
