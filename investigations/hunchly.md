# Hunchly

**Platform:** Chrome/Edge browser extension
**Cost:** $129.99/year (Individual), Team pricing available
**Website:** https://hunch.ly/

## Overview

Hunchly is a web capture tool designed specifically for online investigations. It automatically captures and preserves web pages as you browse, creating a documented evidence trail with hashes, timestamps, and organized case management.

## Key Features

- **Automatic capture** - Records every page you visit during an investigation
- **SHA-256 hashing** - Cryptographic proof of captured content
- **Timestamping** - Records when each page was captured
- **Case management** - Organize captures into separate cases
- **Selector system** - Tag and categorize evidence with custom labels
- **Export options** - PDF reports, HTML archives, evidence packages
- **Offline viewing** - All captures stored locally for review

## Why Use Hunchly for Evidence

1. **Admissibility** - Hash verification and timestamps support evidence authenticity
2. **Completeness** - Captures full page content including images, scripts
3. **Organization** - Built-in case management prevents evidence mixing
4. **Chain of custody** - Automatic logging of investigation activity
5. **Efficiency** - No manual screenshots needed; captures happen automatically

## Workflow

1. Install the browser extension
2. Create a new case for your investigation
3. Enable Hunchly capture
4. Browse normally - all pages are automatically saved
5. Add selectors/tags to important findings
6. Generate reports when investigation complete

## Export Formats

- **PDF Report** - Summary with screenshots and metadata
- **Evidence Package** - Full HTML archive with hashes
- **CSV Export** - Data for analysis in other tools
- **Dashboard view** - Visual investigation timeline

## Comparison with Manual Methods

| Method | Pros | Cons |
|--------|------|------|
| Manual Screenshots | Free | Time-consuming, easy to miss pages |
| Wayback Machine | Free, public | Not all pages archived, delays |
| Hunchly | Automatic, hashed, organized | Cost, Chrome/Edge only |

## Best Practices

- Start a new case for each distinct investigation
- Use descriptive selector names
- Export evidence packages regularly as backups
- Disable capture when not investigating to avoid noise
