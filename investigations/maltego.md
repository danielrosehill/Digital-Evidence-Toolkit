# Maltego

**Platform:** Windows, macOS, Linux
**Cost:** Community Edition (Free), Pro ($999/year), Enterprise (Custom)
**Website:** https://www.maltego.com/

## Overview

Maltego is a powerful OSINT (Open Source Intelligence) and graphical link analysis tool used for gathering and connecting information from various online sources. It visualizes relationships between people, organizations, domains, IP addresses, and other entities.

## Key Features

- **Transform-based data gathering** - Automated queries to multiple data sources
- **Visual link analysis** - Graph-based visualization of relationships
- **Entity discovery** - Find connections between people, companies, domains, emails, social media accounts
- **Extensible** - Large library of transforms from third-party providers
- **Collaboration** - Team features for sharing investigations

## Use Cases for Evidence Gathering

- Mapping relationships between individuals or organizations
- Discovering hidden connections in fraud investigations
- Tracing digital footprints across platforms
- Identifying ownership of domains and infrastructure
- Social media analysis and connection mapping

## Editions

| Edition | Cost | Limits |
|---------|------|--------|
| Community | Free | 12 results per transform, limited transforms |
| Pro | $999/year | Unlimited results, full transform library |
| Enterprise | Custom | Team collaboration, custom transforms |

## Getting Started

1. Download from https://www.maltego.com/downloads/
2. Create a free account for Community Edition
3. Install and configure transforms for your data sources
4. Begin investigations by adding entities and running transforms
