# Operational Security (OPSEC) for Investigations

## Overview

Operational security protects you during evidence gathering and investigations. Poor OPSEC can alert targets, compromise investigations, or put you at personal risk.

## Core Principles

### 1. Separation
- **Devices** - Use dedicated device for investigations when possible
- **Accounts** - Never use personal accounts for research
- **Networks** - Separate investigation traffic from personal use
- **Browsers** - Dedicated browser profile or browser

### 2. Minimal Footprint
- Don't interact with targets unnecessarily
- Avoid clicking on suspicious links
- Don't download files unless essential
- Limit queries that might trigger alerts

### 3. Timing Awareness
- Consider when your activity might be logged
- Avoid patterns that identify you (same time daily)
- Be aware of target's timezone and monitoring

## Practical Checklist

### Before Starting
- [ ] Clear objective defined
- [ ] VPN/Tor configured and tested
- [ ] Fresh browser profile or investigation browser
- [ ] Case documentation system ready
- [ ] Screen recording/capture tools ready

### During Investigation
- [ ] VPN/Tor connected
- [ ] Personal accounts logged out
- [ ] Documenting as you go
- [ ] Not clicking unnecessary links
- [ ] Noting timestamps

### After Session
- [ ] Evidence saved and backed up
- [ ] Browser data cleared (if not using Hunchly)
- [ ] Notes completed
- [ ] Connection closed properly

## Common Mistakes

1. **Logging into personal social media** while investigating
2. **Clicking links** that reveal your IP to target's server
3. **Reusing usernames** from personal accounts
4. **Forgetting VPN** is disconnected
5. **Mixing personal and investigation browsing** in same session
6. **Posting about active investigations** on social media

## Risk Assessment

Before investigating, consider:
- How sophisticated is the target?
- What could they do if they identify you?
- Is this investigation worth the potential risk?
- Do you need professional help?

## When to Involve Professionals

Consider involving law enforcement or professional investigators when:
- Target is potentially dangerous
- Evidence needed for legal proceedings
- Situation involves crimes against persons
- You're out of your depth technically
